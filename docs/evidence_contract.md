# Analysis Evidence v0.1
The schema is a new local contract, not a provider interface. Source SHA-256 refers to the original WAV file bytes. Sample frame zero is decoded time zero. Duration is frame count / sample rate. All channels are included in energy (no stereo cancellation); sample peak and clipping count refer to decoded signed PCM samples, not intersample peaks. dBFS uses 32768 full scale; zero amplitude is represented as null. Windows are nominally 20ms, using floor(sample_rate*0.02) samples, final partial window excluded from onset analysis but included in whole-file RMS and peak. Silent-window fraction uses RMS <= -60 dBFS and full windows only. A pulse estimate is a candidate, not beat verification: onset requires >= 8dB increase and current RMS >= -35 dBFS, minimum 150ms separation; >=4 intervals, median 0.25–1.0s and median absolute deviation <=10% of median. Silence/ambiguous pulse returns UNKNOWN. Absolute thresholds are provisional.

Consumers must verify source SHA and use a separately approved alignment for the final audio master. No automatic PASS from a CANDIDATE status. Optional future extensions: beat grid with uncertainty, note/phoneme timing, segment boundaries, evidence provenance and model license.
